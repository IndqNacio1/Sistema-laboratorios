# Sistema-laboratorios
Sistema de escritorio para la gestión integral de un laboratorio médico, con módulos para usuarios, pacientes, estudios, cobros, inventario, finanzas y sucursales. Desarrollado con React, Tailwind, MUI, Node.js, PostgreSQL y MongoDB.

## Estructura inicial

apps/
  frontend/   Aplicacion de escritorio con React, Tailwind y MUI.
  backend/    API con Node.js y conexion a bases de datos.
docs/         Documentacion, planeacion y analisis del proyecto.

## Comandos iniciales

```bash
npm install
npm run dev:frontend
npm run dev:backend
```

## Modulos principales

- Autenticacion y usuarios
- Pacientes
- Estudios
- Finanzas
- Punto de venta
- Inventario
- Laboratorio / servicios
- Reportes y dashboard
