# Backend

API del sistema de laboratorios.

Tecnologias contempladas:

- Node.js
- PostgreSQL para datos sensibles.
- MongoDB para datos menos estrictos.

Estructura inicial:

- `src/config`: configuracion general del proyecto.
- `src/controllers`: controladores de las rutas.
- `src/middlewares`: validaciones y control de acceso.
- `src/models`: modelos o esquemas de datos.
- `src/routes`: definicion de endpoints.
- `src/services`: logica de negocio.
- `src/utils`: funciones auxiliares.
