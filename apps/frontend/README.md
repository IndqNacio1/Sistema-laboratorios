# Frontend

Aplicacion de escritorio del sistema de laboratorios.

Tecnologias contempladas:

- React.js
- Tailwind CSS
- MUI

Estructura inicial:

- `src/components`: componentes reutilizables.
- `src/pages`: pantallas principales del sistema.
- `src/routes`: configuracion de rutas.
- `src/services`: comunicacion con la API.
- `src/layouts`: layouts generales por tipo de usuario.
- `src/styles`: estilos globales y configuracion visual.
